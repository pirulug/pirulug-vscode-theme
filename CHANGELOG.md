# Change Log

## v0.1.0

- Full color palette refinement for **Dark and Light** themes
- Improved **color synergy** across the theme using `primary` as the base accent
- Enhanced visuals for **Editor, Panels, Widgets, Tabs, and Notifications**
- Contrast adjustments for better readability on dark and light backgrounds
- Extensive **tokenColors** review and improvements for:
  - PHP (classes, functions, variables, keywords)
  - HTML (tags, attributes, strings, comments)
  - SCSS (variables, @rules, !important, mixins)
  - JSON (keys and strings with external colors in palette harmony)
- Improved selection, highlight, and active state visibility
- Theme prepared for future stable releases
